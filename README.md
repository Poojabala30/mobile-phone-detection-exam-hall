
# Mobile Phone Detection in Exam Hall

## Project Description
This project detects mobile phones in exam hall images using computer vision.
It helps in identifying malpractice during examinations.

## Technologies Used
- Python
- OpenCV
- YOLOv8

## How to Run
1. Install Python 3.10
2. Install required libraries
3. Run the Python file

## Output
The system detects mobile phones and draws bounding boxes.
